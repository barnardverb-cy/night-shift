# Night Shift

Night Shift is a retro-style first-person maze shooter where you play as a security robot clearing malfunctioning cleaning drones from a dark office after hours.

## How to Play
- **WASD** – Move
- **Mouse** – Look and turn
- **Left Click** – Shoot
- **Goal:** Shut down all 8 malfunctioning drones.
- **Lose condition:** Your battery reaches 0 after drones bump into you.

## How to Run It
1. Download `index.html` from the repository.
2. Open the downloaded file in a web browser.
